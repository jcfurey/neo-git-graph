# Open the graph

(neo) Git Graph shows the history of every repository in your workspace, including initialized submodules.

Open it from any of these places:

- The **Git Graph** button in the title bar of the Source Control view.
- **(neo) Git Graph** in the status bar.
- The Command Palette: **(neo) Git Graph: View Git Graph**.
- **File History** in the context menu of a file or editor tab, which opens the graph already filtered to that file.

The graph opens in an editor tab and stays in sync with Git. The **Repo** dropdown switches between repositories, and **Branch** limits the graph to one branch.
